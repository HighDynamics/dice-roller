# Dice Roller

A dice roller built with React and [Vite](https://vite.dev). Click a die to roll it.

Live at [highdynamics.github.io/dice-roller](https://highdynamics.github.io/dice-roller/).

## Scripts

- `npm start` (or `npm run dev`): runs the app in development at [http://localhost:5173/dice-roller/](http://localhost:5173/dice-roller/).
- `npm test`: runs the tests once with [Vitest](https://vitest.dev).
- `npm run build`: builds the app into `dist`.
- `npm run preview`: serves the built app at its production path.
- `npm run deploy`: builds the app and publishes `dist` to the `gh-pages` branch.
